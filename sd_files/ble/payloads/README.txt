BLE Custom Payloads Directory
==============================

This directory contains BLE advertisement payload files in JSON format.

These files can be captured using the "Scan Advertiser" feature in the Bluetooth menu,
or created manually following the JSON format described in the documentation.

Example payloads included:
- example_airpods.json - Apple AirPods Pro advertisement
- example_samsung_watch.json - Samsung Galaxy Watch advertisement

To use:
1. Go to Bluetooth Menu > Custom Payload
2. Select a .json file from this directory
3. Review the payload info
4. Press OK to start spamming

Note: Spamming BLE advertisements may cause interference with nearby devices.
Use responsibly and only in controlled environments or for testing purposes.
